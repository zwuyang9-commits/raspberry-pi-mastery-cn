# 完整课程路线

## 第 0 章：准备与安全

目标：会安装 Raspberry Pi OS Lite、启用 SSH、创建虚拟环境、阅读 BCM 引脚编号。

练习：

1. 更新系统并安装 `python3-venv`。
2. 用 `pinout` 查看引脚。
3. 阅读 `SAFETY.md`，计算 LED 限流电阻。

## 第 1 章：GPIO 基础

项目：`projects/01_led_breathing`

理解数字输出、PWM 占空比、资源清理以及为何程序异常时也必须关闭执行器。

## 第 2 章：采集真实世界

项目：`projects/02_environment_station`

理解采样周期、时间戳、传感器噪声、校准和结构化数据。先使用模拟传感器，再替换为
DHT22 或 BME280 驱动。

## 第 3 章：把设备变成服务

项目：`projects/03_local_device_api`

理解 REST API、健康检查、输入约束和局域网访问。生产环境应添加身份验证、TLS 和防火墙。

## 第 4 章：边缘智能

项目：`projects/04_edge_vision_sentinel`

学习“先检测事件，再保存证据”的隐私设计。示例使用可替换检测器，方便接入 OpenCV、
TensorFlow Lite、YOLO Nano 或 Hailo 加速器。

## 第 5 章：旗舰——韧性家庭智能中枢

项目：`projects/05_resilient_home_hub`

中枢接收统一事件，通过声明式规则产生动作，并保留原因。云端不可用时，本地规则仍工作；
传感器异常时进入安全状态。可扩展方向：

- 本地语音：Whisper.cpp + Piper
- 本地视觉：TensorFlow Lite/Hailo
- 能源调度：分时电价与光伏预测
- 无障碍：语音、按钮、手势多模态控制
- 农业：土壤、灌溉、霜冻预警

## 接下来可以怎么玩

不需要按考试一样把每一章做完。你可以挑一个生活里真实存在的小麻烦，例如忘记关灯、
阳台温度太高、担心水管漏水，先用模拟器把逻辑跑通，再接一个真实传感器。等它稳定以后，
再考虑网页控制、设备掉线提醒和断电恢复。每次只加一个变量，项目会更容易维护，也更安全。

## 第 6 章：本地能源调度

项目：`projects/06_local_energy_scheduler`

根据分时电价、光伏余量和设备优先级，在树莓派本地安排洗衣机、热水器、充电器等负载。
算法默认保留关键设备，并将可延迟任务移动到更便宜或太阳能充足的时段。进一步可接入
Modbus 电表、Home Assistant、逆变器 API 和继电器驱动板。

## 第 7 章：本地运行状态控制台

项目：`projects/07_local_operations_console`

把设备心跳、能源安排、自动化动作和本地审计记录汇总为一张状态快照。学习如何从当前状态
生成告警、确认已知问题，并在设备恢复后自动关闭告警。控制台默认输出适合 SSH 阅读的
纯文本，也能输出 JSON 接入局域网页面。整个流程只依赖本地 JSONL 文件，不需要数据库或
云端监控服务。

## 第 8 章：可校验的本地备份

项目：`projects/08_verified_local_backup`

把环境数据、审计日志和配置打包成 ZIP，并用 SHA-256 清单验证每一个文件。学习原子写入、
路径穿越防护、恢复前校验和默认不覆盖原则。备份仍应复制到另一块存储介质，不能只留在原 SD 卡。
