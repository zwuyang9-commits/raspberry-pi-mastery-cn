# 06 本地能源调度器

树莓派在本地计算用电计划，不上传家庭用电数据。调度器优先使用太阳能和低价时段，同时
保证高优先级设备先获得容量。每个时段都写明时长、可用总功率、太阳能余量和电价；同一时段
安排多个负载时，太阳能预算只会扣一次，不会让每台设备都重复使用整份余量。
无法安排的负载会指出最接近的时段，以及还缺多少功率容量或运行时间，便于调整计划。

```bash
python main.py
```

目前的贪心算法把同一时段里的负载按可能重叠来保守预留功率，不生成精确的启动时间。示例只
输出建议，不直接控制市电。真实部署还要接入电表、逆变器数据和设备可运行时间，并使用合规
电气设备及专业安装人员。
> 已经过树莓派 5 软件测试（2026-09-03，代码版本 `36b7614`）。调度算法与计划 CLI 通过；未连接电表或控制市电。
> 详见[实机验证范围与记录](../../docs/real-device-validation.md)。
