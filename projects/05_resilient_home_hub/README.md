# 05 韧性家庭智能中枢

把几种传感器读数整理成统一事件，再用本地规则生成能追溯原因的动作。示例不依赖云端，适合先
验证家庭或小型温室里的控制逻辑。

当前规则：

- 温度 ≥ 30°C：开启风扇。
- 空气质量指数 ≥ 150：开启通风并发出本地提醒。
- 漏水：只接受明确的布尔值；检测到 `true` 时关闭进水阀并报警。
- 设备心跳：关键设备连续两个周期没有响应时，建议进入安全状态。

```bash
python main.py --simulate
python main.py --simulate --audit-log data/home-hub.jsonl
```

指定 `--audit-log` 后，传感器事件、规则动作和设备状态会追加到本地 JSONL 文件。这里仍是模拟
演示，不会直接驱动真实阀门；接设备前还要补持久化队列、看门狗、MQTT 身份验证、独立告警通道
和手动急停。
