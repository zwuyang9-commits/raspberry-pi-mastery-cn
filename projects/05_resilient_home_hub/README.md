# 05 韧性家庭智能中枢

旗舰项目将所有传感器转换成统一事件，通过本地规则生成可解释动作。它不依赖云端，
适用于家庭、温室、养老照护和小型能源系统。

当前规则：

- 温度 ≥ 30°C：开启风扇。
- 空气质量指数 ≥ 150：开启通风并发出本地提醒。
- 漏水：关闭进水阀并报警，优先级最高。
- 设备心跳：关键设备连续两个周期没有响应时，建议进入安全状态。

```bash
python main.py --simulate
```

生产扩展应加入持久化队列、设备心跳、看门狗、MQTT 身份验证和手动急停。
示例已经提供本地心跳监控；生产环境还应把状态持久化，并把告警送到独立通道。
